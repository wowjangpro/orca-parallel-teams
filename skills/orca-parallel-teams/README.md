# orca-parallel-teams — 설치와 첫 사용 안내

Orca ADE 에서 병렬 작업을 3계층(메인 세션 = 창구 → 트랙 워커 → 워커 안 이름 있는 agent team)으로
운영하는 절차를 담은 Claude Code **스킬**입니다. 프로젝트와 무관합니다.

> 이 README 는 스킬 폴더만 직접 복사해 쓰는 방법을 설명합니다. 플러그인으로 설치하는 방법은
> 저장소 최상위 README 를 보세요.

## 설치(폴더 복사)

`orca-parallel-teams` 폴더를 통째로 대상 PC 의 사용자 전역 스킬 디렉토리에 넣습니다.

- macOS · Linux: `~/.claude/skills/orca-parallel-teams/`
- 결과 경로: `~/.claude/skills/orca-parallel-teams/SKILL.md`

특정 프로젝트에서만 쓰려면 그 리포의 `.claude/skills/` 아래에 같은 이름으로 둡니다.
Claude Code 를 새로 띄우면 목록에 잡힙니다. 폴더 안 세 파일은 서로 참조하므로 함께 옮깁니다.

## 설치 뒤 확인 3가지 (SKILL.md §0 과 같은 항목)

1. `orca status` 의 `runtimeReachable` 이 true 인가.
2. `orca --version` 이 일반 사용자 권한으로 되는가 — 실행 파일 심볼릭이 root 소유 `0700` 이면
   워커에게 주입되는 명령이 전부 실패합니다(권한을 고친 뒤 진행).
3. agent team 이 켜져 있는가 — `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`,
   그리고 무인 워커가 권한 프롬프트에서 멈추지 않도록 Orca 의 claude 기본 인자 확인.

## 새 PC 에서 처음 쓸 때

SKILL.md §0 의 5번 — **읽기 전용 프로브 1회**를 먼저 돌립니다.
워커 1명 ＋ 이름 있는 팀원 2명의 직접 왕복, 창구 쪽 통지·질문·종결 경로가 실제로 도는지 봅니다.
「된다/안 된다」는 환경마다 다시 재는 항목입니다 — 이 문서의 실측값은
작성자 환경(Orca 1.4.205 · macOS)에서 2026-09-19 ~ 09-20 에 잰 값입니다.

## 함께 볼 것

- 보안 검수 팀원(security)의 역할·단계·판정은 SKILL.md 「보안 검수」 절이 정본입니다.
  점검 항목은 두 층입니다 — 공통은 이 폴더의 `security-checklist.md`(폴더째 복사하면 함께 옮겨집니다),
  프로젝트마다 다른 것은 각 프로젝트 루트의 `docs/security-review/checklist.md`.
  공통 체크리스트의 근거 문서(법령 · 인증기준)는 국내 서비스 기준이고 조문 대조 전이라,
  다른 조직은 프로젝트 체크리스트에서 근거를 바꿔 쓰고 심사 증적에 조문 번호를 바로 인용하지 않습니다.
- 브라우저 검증 도구는 **사용자·프로젝트가 지정한 것**을 씁니다(SKILL.md §2 마지막에서 두 번째 행).
  대상 PC 의 사용자 전역 `CLAUDE.md` 에 그 지정이 있는지 먼저 확인하세요.
- 판정 술어(§6)는 도구별 문자열에 의존합니다. 다른 빌드 도구를 쓰면
  「강제 실행의 증거 문자열」을 그 도구 기준으로 먼저 확인한 뒤 세십시오.
